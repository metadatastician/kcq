query and lint tool written in AffineScript and compiled to WebAssembly. *At
this commit it does nothing.* No source file parses, so no command is
implemented. This file records that state exactly, and records the guards that

=== The honest nuance you must not lose

* "`just validate` passes" means the metadata is well-formed. It says nothing
  about the YAML processor, which does not exist yet.
* `deed_lint.js` checks grammar only. It does not check that a clause's
  claims are true.
